## Introduction 

The goal of this project was to optimize the design of a wind turbine blade. First, I analyzed the performance of the given standard blade design using three different methods: a CFD simulation in Ansys Fluent, experimental wind tunnel data, and applying blade element momentum (BEM) theory to calculate the aerodynamic forces on the blades in a MATLAB script. Then, I created a new blade design using a similar procedure as the standard blade aiming to increase the power coefficient of the turbine. Finally, I analyzed the performance of the new blade design using the same MATLAB code and compared this to the standard blade performance.
